# awesome-browser-agent-tasks

A curated collection of real-world tasks, prompt patterns, and task packs for AI browser agents.

This repository exists to make browser-agent work concrete. A lot of discussion around browser agents stays vague. This repo focuses on practical, markdown-first examples that show the kinds of browser tasks people actually want agents to perform.

It is intentionally simple:

- not a framework
- not a benchmark engine
- not a SaaS product
- just a clean, useful, expandable content repository

It is maintained as an open resource by the CopilotKiwi team. Learn more at [copilot.kiwi](https://copilot.kiwi).

## Who this is for

- browser-agent builders
- developers
- researchers
- founders
- testers
- power users
