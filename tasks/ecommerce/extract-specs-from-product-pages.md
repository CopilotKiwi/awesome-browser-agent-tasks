# Extract Specs From Product Pages

## Goal
Pull structured specifications from a set of product pages.

## Example Prompt
Review these product pages and extract the main specs, dimensions, materials, and included accessories.

## Task Type
- Extraction

## Difficulty
- Hard

## Skills Required
- extraction
- scrolling
- navigation

## Success Criteria
The agent returns comparable specs for each product without mixing fields.

## Notes
Useful for technical product comparison and catalog work.
