# Compare Shipping And Return Policies

## Goal
Compare store policies that affect buying decisions.

## Example Prompt
Review these stores and compare shipping timelines, return windows, return costs, and any special return conditions.

## Task Type
- Comparison

## Difficulty
- Medium

## Skills Required
- navigation
- extraction
- comparison

## Success Criteria
The agent highlights the policy differences clearly enough to support a buying decision.

## Notes
Often requires moving between product pages and policy pages.
