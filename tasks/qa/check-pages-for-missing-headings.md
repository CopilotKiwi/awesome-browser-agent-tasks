# Check Pages For Missing Headings

## Goal
Check whether important pages are missing a visible main heading or clear heading structure.

## Example Prompt
Review these pages and tell me which ones appear to be missing a clear H1 or have weak heading hierarchy.

## Task Type
- QA

## Difficulty
- Easy

## Skills Required
- extraction
- comparison

## Success Criteria
The agent flags pages with missing or weak heading structure and summarizes the issue.

## Notes
Useful for content QA and accessibility review.
