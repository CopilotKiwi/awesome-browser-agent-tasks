# Compare Page Elements Against A Checklist

## Goal
Verify whether a page or set of pages contains required visible elements.

## Example Prompt
Check these pages against this checklist: headline, CTA button, pricing section, contact link, and trust signal. Tell me what is missing.

## Task Type
- QA

## Difficulty
- Hard

## Skills Required
- extraction
- comparison
- scrolling

## Success Criteria
The agent evaluates the checklist consistently and reports missing or unclear elements.

## Notes
Useful for landing page review, QA audits, and competitive teardown work.
