# Identify Contact Or Enquiry Pages

## Goal
Find the most relevant contact or enquiry page on a set of company websites.

## Example Prompt
Find the best contact or enquiry page for each of these company websites and return the page URL plus the contact method used.

## Task Type
- Navigation

## Difficulty
- Easy

## Skills Required
- navigation
- extraction

## Success Criteria
The agent identifies the most useful outbound contact page or form for each site.

## Notes
Helpful when building sales workflows or lead enrichment steps.
