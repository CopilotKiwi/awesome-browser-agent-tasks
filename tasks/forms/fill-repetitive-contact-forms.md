# Fill Repetitive Contact Forms

## Goal
Use the same set of business or personal details to complete multiple contact forms.

## Example Prompt
Fill these contact forms using the company details I provided, but stop before submitting and show me what was entered.

## Task Type
- Form filling

## Difficulty
- Easy

## Skills Required
- clicking
- form entry
- navigation

## Success Criteria
The agent maps the provided details into the correct fields consistently across forms.

## Notes
Useful for outreach, supplier enquiries, and repetitive admin work.
