# Collect Competitor Feature Differences

## Goal
Identify and compare feature positioning across competitor websites.

## Example Prompt
Review these competitor sites and list the main features each one highlights, then summarize the biggest differences.

## Task Type
- Research

## Difficulty
- Hard

## Skills Required
- tab management
- extraction
- comparison
- navigation

## Success Criteria
The agent produces a structured list of feature differences without mixing claims between companies.

## Notes
This gets harder when sites use marketing-heavy language instead of clear feature tables.
