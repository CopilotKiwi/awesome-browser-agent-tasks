# Extract Company And Role Details From Listings

## Goal
Extract structured hiring information from job listings or career pages.

## Example Prompt
Go through these job listings and return the company name, role title, location, employment type, and any salary information shown.

## Task Type
- Extraction

## Difficulty
- Hard

## Skills Required
- extraction
- navigation
- comparison

## Success Criteria
The agent returns a clean set of listing records with the requested fields.

## Notes
Good benchmark for structured extraction from inconsistent layouts.
