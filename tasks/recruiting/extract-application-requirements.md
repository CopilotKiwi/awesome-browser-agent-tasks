# Extract Application Requirements

## Goal
Pull the required materials or steps from job application pages.

## Example Prompt
Review these job listings and extract the application requirements, including experience, documents, deadlines, and any mandatory questions.

## Task Type
- Extraction

## Difficulty
- Medium

## Skills Required
- navigation
- extraction
- scrolling

## Success Criteria
The agent captures the required application details accurately from each listing.

## Notes
Listings often hide details below expandable sections or on secondary pages.
