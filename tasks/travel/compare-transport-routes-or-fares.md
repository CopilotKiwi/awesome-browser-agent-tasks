# Compare Transport Routes Or Fares

## Goal
Compare travel options based on route, duration, price, and policy.

## Example Prompt
Compare these transport options and summarize the route, total fare, travel time, baggage or change policy, and which option looks best overall.

## Task Type
- Comparison

## Difficulty
- Hard

## Skills Required
- extraction
- comparison
- tab management

## Success Criteria
The agent returns a structured comparison with enough detail to support a decision.

## Notes
This becomes harder on dynamic travel sites with multiple fare classes.
