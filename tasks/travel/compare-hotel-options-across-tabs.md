# Compare Hotel Options Across Tabs

## Goal
Compare hotel listings based on price, policy, and basic fit.

## Example Prompt
Compare these hotel pages and tell me which one looks best based on price, cancellation policy, location details, and visible rating information.

## Task Type
- Comparison

## Difficulty
- Medium

## Skills Required
- tab management
- extraction
- comparison

## Success Criteria
The agent returns a useful comparison and a clear best option based on the requested criteria.

## Notes
Useful for travel planning and booking research.
