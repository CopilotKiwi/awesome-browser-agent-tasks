# Extract Baggage Policies

## Goal
Find and summarize baggage rules from airline or travel-provider websites.

## Example Prompt
Review these airline pages and extract the carry-on and checked baggage rules, weight limits, and any notable fees or restrictions.

## Task Type
- Extraction

## Difficulty
- Medium

## Skills Required
- navigation
- extraction
- scrolling

## Success Criteria
The main baggage rules are captured correctly for each provider.

## Notes
Good test of policy extraction from travel sites with nested help content.
