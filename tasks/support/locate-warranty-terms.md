# Locate Warranty Terms

## Goal
Find and summarize warranty coverage information from a website.

## Example Prompt
Find the warranty terms for this product or store and summarize the coverage length, exclusions, and claim process.

## Task Type
- Navigation

## Difficulty
- Medium

## Skills Required
- navigation
- extraction

## Success Criteria
The agent finds the warranty information and returns the main terms in a readable summary.

## Notes
This often requires moving into help, support, or policy pages.
