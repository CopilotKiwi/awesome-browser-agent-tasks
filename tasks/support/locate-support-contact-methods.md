# Locate Support Contact Methods

## Goal
Find the available support channels for a product or company website.

## Example Prompt
Find how this company offers support and return the support email, phone, live chat, ticket form, and help center URL if visible.

## Task Type
- Extraction

## Difficulty
- Easy

## Skills Required
- navigation
- extraction

## Success Criteria
The agent identifies the main visible support contact methods and where they were found.

## Notes
Useful for support research, vendor comparisons, and QA checks.
